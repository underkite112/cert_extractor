# TTA 인증서 발급용 데이터 추출기

관리 목록(xlsx) + 시험결과요약서(PDF) + 회의록(.hwp, 선택)을 업로드하면
인증번호 기준으로 매칭해서 인증서 제작 및 홈페이지 등록에 필요한 필드(업체명, 제품명, 모델명,
제조자/제조국가, 인증연월일, 유효기간, 인증기준, 인증범위, Test Highlights)를
표로 뽑아주고 엑셀로 다운로드할 수 있는 Streamlit 앱입니다.

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 주의사항 / 한계

- **추출 로직은 정규식 기반**이라, 시험결과요약서 표지 레이아웃이 지금까지 본 6개
  양식과 크게 다르면 일부 필드가 비거나 잘못 들어갈 수 있습니다. 화면의 표는
  `st.data_editor`로 바로 수정 가능하니, 다운로드 전에 한 번씩 확인하세요.
- 관리 목록 엑셀의 컬럼명이 `업체명 / 영문명 / 제품명 / 모델명 / 파생모델명 /
  인증기준 / 인증번호`와 다르면 코드 내 해당 컬럼명을 맞춰 수정해야 합니다.
- `.hwp` 회의록 파싱은 `pyhwp`(hwp5html)를 사용합니다. Streamlit Cloud 등
  일부 환경에서는 시스템 패키지 제약으로 설치가 안 될 수 있으니, 안 될 경우
  회의록 없이 쓰거나 로컬에서 표 내용을 미리 텍스트로 뽑아 붙여넣는 방식으로
  우회하세요.
- 제조자/제조국가가 "이름/국가" 한 줄로 붙어 있는 경우와, "제조자"/"제조국가"가
  따로 표기된 경우를 모두 처리하도록 만들었습니다. 제조자 표기가 아예 없으면
  업체명을 그대로 사용합니다.
